# Coder P2: js/picture-print.js (print sheets and the body map)
Follow COMMON-CODE-24.md. You own js/picture-print.js (+ your CSS block). Another coder writes js/pictures.js at the same
time: use only `App.pictures.get(id)` and `App.pictures.svg(set, { pins: 'numbers'|'dots'|'none', highlight })`, and if
they are missing (stub) fall back to your own small svg builder from PICTURE_SETS + PICTURE_ART (viewBox from art.vb,
art.svg, numbered pins at part x/y), so that your page works either way.
- `App.picturePrint.sheet(el, set)`: the Print tab of a set. Preview + options (remembered in state.settings.picPrint):
  paper A4 / Letter, "Blank labels" or "Filled in", furigana on/off, English on/off, answer key page on/off. Diagram: the
  picture large with numbered pins, then numbered lines (blank or word). Cards: a grid of emoji with a line under each.
  Answer key on a new page: number, word with furigana, English. Footer line: the app attribution and "Draft Japanese:
  not yet reviewed by a native speaker". Print through App.printWith(size, margin) as js/writing.js does (read it and
  js/handout.js for the print pattern and the html.pr-page rules); printed pages are always light; check page counts with
  Playwright page.pdf + pdfinfo (one set = 1 page, or 2 with the key).
- Body map, V.bodymap for #/pictures/bodymap (the route exists; define the view the scaffold's route expects, check
  js/app.js): on screen, front and back body (sets from PICTURE_BODYMAP.sets, fallback ['body-front','body-back']) with
  dot pins; the clinician's questions (PICTURE_BODYMAP.ask) with speaker buttons above; the patient taps a pin → the
  word very large in Japanese (furigana) with English under it and a speaker, and "ここ が 痛《いた》い です か。" style
  confirmation is NOT generated by code (only show the data's sentences). Under it the pain words (PICTURE_BODYMAP.words)
  as large tappable chips that speak. Nothing is stored (no patient data; no notes field). Print = one A4 / Letter
  handout: both figures, the questions, the pain words, and a plain number line 0 to 10 labelled only "0" … "10" with
  the data's own caption if `PICTURE_BODYMAP.scale` exists ({ ja, en }), otherwise no caption. NO faces, NO wording
  from any published pain scale. Works with empty data (figures only).
- A link to the body map is added by you nowhere else (the pictures list and the Psychiatry pages link to it; not your files).
