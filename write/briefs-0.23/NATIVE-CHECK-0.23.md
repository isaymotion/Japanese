## New N5 lessons (lessons-28, -29) and N5 reviews (lessons-33)
- dake-shika: 三時間 しか 寝ません でした (or 寝て いません / 眠れません でした); 家族 は 母 しか いません vs 母 だけ です.
- indefinites: 最近 は 何 も 楽しく ありません as a patient's line. mada-mou: まだ 食べません glossed "not going to eat yet".
- suki-jouzu: 「前 は 映画 が 大好き でした。 今 は あまり 見ません。」; お話ししましょう said by a doctor.
- ni-iku: the warning against 何 を し に 来ました か as an opener; ご家族 は 何時 ごろ 会い に 来ます か (来られます か?).
- adverbs-ku-ni: 私 の 手 を 強く 押して ください in a strength test (握って / 押し返して?); 部屋 を 少し 明るく しましょう か.
- ne-yo: whether お薬 は 毎日 飲んで ください よ is heard as nagging; conjunctions: だから blunt, ですから preferred.
- reviews: 熱 は 二日前 から です; この 薬 は ご飯 を 食べた 後 で 飲んで います か (後 に?); 悪い 夢 は 怖い です ね.

## New N4 lessons (lessons-30, -31, -32) and N4 reviews (lessons-34, -35)
- baai: 地域 の 相談窓口 as the generic "local crisis line" (電話相談?); 死にたい 気持ち が 強く なった 場合 は、 一人 で 我慢しないで、 すぐ 病院 に 連絡して ください (tone).
- nara: 眠れない なら、 寝る 前 に スマホ を 見ないで ください (見ない よう に して ください gentler?). aida-made: 元気 な 間 vs 元気 な うち.
- garu: is 痛がる / 嫌がる about an adult patient "distant or childlike"? おっしゃって います about a patient in a staff handover; 〜て ほしがって います.
- to-iu-n4: 田中 だ と いう 人 taught as wrong for "called Tanaka". reported-requests: 控える vs 減らす.
- compound-verbs-n4: 毎日 の 気分 を 日記 に 書き続けて いただけます か (気分日記?); 手 が 震え出します vs 震えて きます; 〜終わって ください vs 〜終えて ください.
- sa-mi: 体 の だるさ は、 朝 と 夜 で 違います か; 今 の つらさ は、 一番 つらかった とき と 同じ ぐらい です か; 悲しみ は、 先月 と 同じ ぐらい 強い です か.
- reviews: 少し つらそう です ね with a fever; 一緒 に 住んで いる 方 が いる か どうか (いらっしゃる?); 「早く 帰れ」 と 言う 声 が 聞こえて、 家 に 帰ろう と しました (a patient acting on a command voice, as an example); お待ち に なって います for a patient's family; 家族 も 心配 させて しまいました.

## Lesson extras (lesson-extra-1..8)
- interview-patterns: the mistake pair 自殺 したい です か (struck through) → 死にたい と 思う こと は あります か, and the note that 〜たい です か is blunt while 自殺 を 考えた こと は あります か is also direct and fine.
- Register mistakes shown as "wrong": 私 は 医者。; ご家族 の こと を 話して。; 落ち込んで いる の？; そんなに 速く 話さない で。
- "Wrong" lines that are real in some speech: 田中さん は 来ます と 思います; 眠られません; 食べさされました (Kansai); ジム に 通う と 思います (grammatical as a prediction); 日本語 を できます.
- kenjougo mistake 3: humble forms for your own hospital director when talking to a patient. keigo: 先生、 この 資料 を ご覧 に なります か.
- commands: 声 は どんな こと を する よう に 言います か. te-shimau: 眠れない とき は、 一度 ベッド から 出て みて ください.
- nai-form: 薬 を 自分 で やめないで ください (自分 の 判断 で?). sonkeigo: お薬 の 説明書 for a medicine leaflet.
