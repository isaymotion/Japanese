# Write /home/claude/work/new/sound-pairs.js (sound-pair listening drill)
Read COMMON-WRITE.md first. Seed and shape: /home/claude/japanese/js/data/sound-pairs.js (copy its header).
Each item is two real, common words (or short forms) that differ only in one sound feature; the learner hears one and chooses which. Both are recorded by a neural voice reading the text, so write each word the way it is normally written (kanji with furigana where usual) and prefer words the voice will read unambiguously in isolation (avoid homographs with two common readings; if a word is ambiguous in kanji, write it in kana). Both words and their English must make the difference clear.
`guide` types (exactly these ids), with a 2–3 sentence English explanation each (beats, how to hear it, a tip):
- long: short vs long vowel (おばさん / おばあさん, ビル / ビール, 雪《ゆき》 / 勇気《ゆうき》)
- sokuon: without vs with small っ (来《き》て / 切《き》って, 音《おと》 / 夫《おっと》, 坂《さか》 / 作家《さっか》)
- n: without vs with ん (only real, common pairs; fewer is fine)
- youon: large やゆよ vs small ゃゅょ (病院《びょういん》 / 美容院《びよういん》 — include this one, 今日《きょう》 / 器用《きよう》, 旅行《りょこう》 / 利用《りよう》)
- voicing: unvoiced vs voiced (天気《てんき》 / 電気《でんき》, 柿《かき》 / 鍵《かぎ》, 金《きん》 / 銀《ぎん》)
No pitch-accent pairs (the voice cannot be trusted for pitch), and no pairs that sound the same (聞く / 効く).
Aim for about 150 items in all (roughly 40 long, 35 sokuon, 15 n, 30 youon, 30 voicing; fewer in a type rather than forced or obscure pairs). Prefer N5/N4 words, and clinic or ward words where a real pair exists. Each item: [type, a, aEn, b, bEn] — a and b in notation, aEn/bEn short English glosses. No two items with the same pair. Avoid words about violence, crime, sex, death or that could upset a patient. Verb forms are fine (来て come / 切って cut).
Check with the commands in COMMON-WRITE.md.
