# Lines for a native-speaking clinician (Hanashimashō 0.28.0, N1 first half)

From the independent reviewers of each file. Readings are left out here; open the lesson to hear the line.

## lessons-45.js (The moment something happens)
- 祖父 は 朝 出かけた なり、 まだ 帰って きません (is 〜た なり too literary?)
- 主人 は 仕事 から 帰る なり、 お酒 を 飲み始める ん です (habitual なり)
- 息子 は 部屋 に 入って くる なり … と 大声 で 言いました (なり in polite speech)
- 本日 を もって、 当院 の 夜間 外来 は 終了 いたします (notice wording)
- 退院後 の ご報告 かたがた、 お礼 に 参りました
- 弟 は 家 に 帰る が 早いか、 また 遊び に 出かけて 行った (quiz stem)
- Open: how natural habitual 〜なり is; how rare 〜た なり is.

## lessons-46.js (Reaching the extreme)
- 家族 の 名前 に 至って は … (a family member speaking)
- 先生方 に は … 感謝 に 堪えません (very formal family)
- 呼びかけ に も 応じず … 微動 だに しなかった (narrative; a chart would write 体動 なし)
- 一円 たり とも 無駄 に は できない; 何人 たり とも (exception wording)
- 疲れ が ひどくて、 シャワー を 浴びる こと すら おっくう です

## lessons-47.js (If and only if)
- 母 が 倒れた と あって は、 じっと して は いられません でした (past-tense とあっては)
- 若い 頃 なら いざ 知らず、 この 年 で 夜勤 を … (いざ知らず in speech)
- 軽症例 なら まだしも、 … 避ける べき だ (まだしも in writing)
- 一回 なら まだしも、 毎晩 … つらい です よ ね (resident's tone)
- 原則 と して、 ご本人 の 同意 なし に ご家族 へ 病状 を お伝え する こと は ありません (consent wording; hospital practice, no legal claim)
- 退院 できたら できた で、 今度 は …

## lessons-48.js (Even so)
- 年 を 取った と いえども、 自分 の こと は 自分 で 決めたい の です
- 職場 で の 重圧 が 生来 の 真面目 な 性格 と 相まって … もの と 考えられる (case-report style)
- 幻聴 は 消失 に は 至らない まで も、 その 頻度 は 減少 して いる
- お薬 の 効果 と ご家族 の 支え が 相まって … (相まって said to a family)
- 理由 が 何 で あれ、 一人 で 抱え込む 必要 は ありません (too stiff for the resident?)
- 「早く 気づいて いれば よかった もの を」 と、 ご自分 を 責めて いらっしゃる ん です ね (tone of the reflection)
- もの を is written with a space in the app only so that the romaji reads "o"; the lesson says so.

## lessons-49.js (Grounds and standards)
- 未熟 な ゆえ に (form in the table)
- 孫 の した こと とて、 どうか お許し ください
- 心配 すれば こそ、 ご両親 は … (すれば vs して いる)
- ご本人 の 希望 に 照らして: is it really wrong (quiz 3)?
- 青木さん なり に 本当に 努力 して こられた (can なり に sound condescending said to a patient?)
- 一度 と して 仕事 を 休んだ こと は ありません でした
- 法律 と 当院 の 方針 に 従って 進めます (admission phrasing)

## lessons-50.js (How it looks and sounds)
- 差し出がましい よう です が、 ご家族 に も 一度 確認 して は いかが でしょう か (first-year to a senior)
- いつ から とも なく、 人 と 会う の が おっくう に なって しまいまして
- 話しかける と、 嫌そう に 顔 を そむけられる ん です ね
- 症状 は 行きつ 戻りつ しながら も、 徐々 に 改善 した
- 入院 生活 は 規則ずくめ で、 窮屈 に 感じる 方 も 多い です
- 頭 に 霧 が かかった か の ごとき 感覚 が 続いて おります (older patient)
- だいぶ 春めいて きました ね (a remark on the season, kept as the typical spoken use)

## lessons-51.js (Must, must not, cannot)
- それで、 今 お仕事 を 休んで いる ご自分 を 責めて しまう の でしょう か (reflection after a patient quotes 働かざる 者 食う べからず)
- 辞める こと を 余儀なく されました (in speech)
- 軽い 副作用 です ので、 ご心配 に は 及びません (too stiff for patients? the lesson recommends 〜なくて 大丈夫 です)
- 涙 を 禁じ得ません でした (a parent)
- 主治医 に 報告 せず に は すまない
- 信じる に 足りない もの が 多い (足らない?)
- 今度 こそ 真相 を 明らか に せず に は おかない
- 合格 す べく、 毎日 勉強 を 続けた (す べく)
- Open: whether 余儀なく する is wrong or only archaic (the lesson says to use される / させる).

## lessons-52.js (Judging and summing up)
- 私 は 説明 が 早口 に なる きらい が ある ので … (きらい about oneself)
- 熟練 した 医師 に して 判断 に 迷う ほど の、 難しい 症例 で あった
- 片道 五十キロ から ある 道のり を …
- 健康 あって の 仕事 です から … (to a patient)
- 薬 の せい で 一日中 こんなに 眠くて は かなわない よ (a patient)
- 調子 は 良く も 悪く も ない と いった ところ です
- 青木さん の 今後 の ご健康 を、 スタッフ 一同 心 より 願って やみません (discharge card)

## Placement (meta.js, five N1 questions)
- 入院 して から と いう もの、 夜 は よく 眠れる よう に なりました
- ご家族 の 支え なくして は、 ここ まで の 回復 は ありません でした
- 一人 で 歩く こと は おろか、 起き上がる こと すら できません でした
- 手術 の 後、 父 は 一か月 の 入院 を 余儀なく されました
- ご家族 の 不安 は 想像 に 難く ありません

## Kanji and dictionary words (kanji-n1a..e.js, dict-n1-1..3.js)
- 乳房 read にゅうぼう (clinical) vs ちぶさ; 博士 はかせ / はくし; 執着 しゅうちゃく / しゅうじゃく; 剣 given as つるぎ (けん is commoner alone).
- 不穏 glossed "unrest, agitation" with a note that it is a chart word for an unsettled patient; 筋強剛 for rigidity; the 洞察 / 病識 note; the 脅迫 / 強迫 note; 拒食症 "the everyday word for anorexia nervosa"; 精神分裂病 as the old name of 統合失調症.
- 狂: note "Do not use words with this kanji to describe patients."
- 准看護師 glossed "licensed practical nurse, assistant nurse" (no claim about any system).
- 雰 has one real word (雰囲気); 雰囲気作り fills the checker's two-word minimum.
- Name kanji carry (surname), (given name) or (place name) words: 藤 沢 井 宮 崎 伊 佐 浜 江 郎 智 弘 彦 浩 宏 李 阿 潟 也 之 靖 昌 磯 旭 錦 駒 堀 岐 曙 辰 淳 聡 嘉.
- する-typing kept by the reviewers although rare with する: 一覧, 懲戒. 馬鹿 is typed n. 属する and 呈する are typed vi.
