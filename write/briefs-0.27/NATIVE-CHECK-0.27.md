# Lines for a native Japanese-speaking clinician (0.27.0)
From the three reviewers. Files js/data/picture-sets-more-1.js (shops, pharmacy-counter), -more-2.js (kitchen-tools, ward-room), -more-3.js (sports-hobbies, clock-calendar).

## shops
- 体 の ため に、 八百屋 で 野菜 を たくさん 買って います。
- 袋 は いります か。 (staff may say レジ袋 は ご利用 です か)
- お金 は あちら の レジ で 払って ください。 (staff may say お会計 は あちら で)
- Levels of 店員, 袋 (no official list). The set is N4 because most of its words are.

## pharmacy-counter
- 薬袋 read くすりぶくろ (pharmacy jargon: やくたい).
- 番号 for the number ticket (the real word is 番号札, kept out to stay within the N3 limit).
- シロップ vs 水薬 for an adult's liquid medicine.
- 腰 が 痛くて、 湿布 を 出して もらいました。 (出して もらう for "was given / prescribed")
- 粉薬 が 苦手 な 方 は、 お知らせ ください。
- 処方箋 を お預かりします。 Levels of 湿布, 薬剤師.

## kitchen-tools
- お玉 で 鍋 の みそ汁 を すくいます。
- 炊けた ご飯 を しゃもじ で 軽く 混ぜます。
- ご飯 は お茶碗 半分 ぐらい 食べられました。 (part word 茶碗, sentence お茶碗)
- Levels of しゃもじ (N3), フライ返し (N4), やかん (N4), ボウル, スポンジ, エプロン; the dictionary rates 瓶 N3.

## ward-room
- 名札 for the bedside name sign (or ベッドネーム / ネームプレート); 名札 の お名前 は 合って います か。
- スリッパ は 脱げやすい ので、 かかと の ある 靴 を 履いて ください ね。
- 今日 は シーツ を 新しい の に 替えます ね。 (or シーツ を 交換します ね)
- テーブル for the over-bed table (ward word: オーバーテーブル); 電気 for the ceiling light.
- The dictionary rates 枕, 毛布, ナースコール N3; the set says N4.

## sports-hobbies
- 今 でも 釣り に 行きます か。
- 子供 の とき から ピアノ を 習って います。 (or 子供 の 頃 から)
- Levels: 読書, 水泳, 釣り are N4 here; some lists say N3. ピアノ and ギター are instruments used as hobby words.

## clock-calendar
- 週末 は 何 を して います か。 (or 何 を して 過ごして います か)
- 祝日 は 受付 が お休み です。 (or 外来 は お休み です)
- 目覚まし時計 の 音 が 聞こえません でした。
- 今日 は 午後 から 検査 が あります。 (written by the main chat in place of a date question, which sat too close to orientation items of screening tests)
